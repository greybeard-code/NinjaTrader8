# TradeSaber Predator helpers

Indicators for use with [TradeSaber's Predator](https://tradesaber.com/).

- **gbSaberADXFilter.cs** - ADX filter for Predator.
- **gbSaberTOWilliamsR.cs** - Trader Oracle WilliamsR for Predator.
- **gbPaperFeet.cs** - Modified Trader Oracle PaperFeet that plots Predator-ready signals
  ([video](https://youtu.be/HeJOxQ7_fhM)). Program Predator to enter Long on "Long" and Short on
  "Short"; use "ExitLong" and "ExitShort" for exits. Adds a checkbox to generate signals on yellow
  dots and customizable crossover triggers.
